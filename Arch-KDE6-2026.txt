Fix IP problem for X410. Cant find screen problem

OPEN POWERSHELL FROM MICROSOFT AND TYPE: ipconfig

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL in POWERSHELL so xserver works.

SAVE IP FROM POWERSHELL HERE: 172.30.16.1

NOW GO BACK TO ARCH Terminal and paste this.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip adress here from POWERSHELL and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - alot of problem fixed ARCH OS =]
